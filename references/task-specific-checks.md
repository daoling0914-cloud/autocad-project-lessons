# 按任务模式选择检查

仅阅读适用于本次请求的分支。以下补充来自师兄提供的经验整理包，已重新组织；来源与证据范围见 [source-notes.md](source-notes.md)。

## 先决定几何依据

| 模式 | 应保留或验证的依据 |
| --- | --- |
| 已给实尺寸的新建图 | 真实几何、尺寸链和原生测量；冲突先查单位、基准与标注因子 |
| 通用参数详图 | 参数符号的意义、构造层次、各视图对应及所需版式 |
| 图片复绘 | 清晰标注优先；比例来源及不可确定的部分单独记录 |
| 原 DWG 局改 | 允许变化项和不变项；不把家具/姓名修改扩大到建筑主体 |
| 允许自主设计 | 采用的尺寸与设计决定；不能描述成原件精确复原 |
| 可编辑转换 | 用户需要的对象类型、单件边界与编辑粒度 |

`D`、`D1`、`H` 等可能是通用参数，不是要求选择某个固定直径或高度。保留参数的图仍应检查构造、曲线、剖面和标签对应关系；示意模式不等于可以忽略原图细部。原生尺寸中的 `<>` 配合前后缀有合法表达用途，与硬写一个常量遮盖量测值的做法不同。

只要求二维时不默认增加三维、图框或额外说明。用户后来明确放宽为自主尺寸时，更新依据并继续，不以已取消的逐件复刻条件阻止执行。

## 分项交付与模板

先列任务标识及每项应有内容，再映射到文件和页数。一个任务可以包含多张图或多页；按任务拆分时不能把每个图形都另存成一个任务文件。合版与单项版分别按要求核对。

例如两组实验各有三项任务，其中一项需要三页，其余每项一页：按任务交付是六份 PDF、合计八页。这个数量关系只适用于该例，不是固定输出规则。

空白模板可能只要求图框，后续任务才加入图形或尺寸。验收其图幅、留边及允许的标题栏内容，不因文字少就自动补图或报空输出。按矩形裁切分题时检查是否混入邻题、截断延长线或漏辅助线。

各任务的 PDF 页数、纸张可不同。`scripts/check_delivery.py --plan ...` 支持分别声明要求；检查任务清单无法自动证明原任务书没有漏项，仍须人工核对任务覆盖和顺序。

## 三视图与表面点

先声明模型坐标、投影法、观察方向及各视图在纸面的展开方式。验证对应点共享的坐标、长/高/宽的对应关系和可见性；不要把某一个图例的坐标正负号固定到所有任务。

正三棱柱的某一侧投影宽度可能是底边的高，而非边长本身；从几何与观察方向推导。圆柱表面点满足截面圆方程，给出一个横向坐标通常还有前后两解，应声明所选半表面并验证高度范围和可见性。重合的中心线、轮廓和辅助线要按表达需要确定线型优先级，避免叠画互相干扰。

## 已有三维模型的装配与爆炸出图

本分支用于模型检查或出图配套；新建、修改三维模型时使用随包的 [CAD 建模指南](upstream/cad/guide.md)。确认交付需要的是实体、曲面还是网格，不能把 STL 或网格称为可做实体布尔操作的模型。

视图、装配与爆炸从同一版模型派生。拆开前后核零件/组的对应关系、刚体变换、体积与尺寸；未经要求不通过缩放零件制造爆炸间距。总成组、实体、采购件和实际零件数量分别说明。

AABB 重叠适合筛干涉候选，但不是最终实体干涉结论。对关键配合检查实际实体交集，并区分接触和正体积穿插；“总成之间通过”不能扩写为“每个总成内部逐件通过”。仅有外观照片时不声称隐蔽结构和零件数精确一致。

## 整件编辑及跨格式转换

块/组整体可移动不代表分组正确。以完整家具、人物或设备本体确定对象集合；在测试副本中移动一件，检查本体是否完整跟随、原位是否有残留、邻件是否被带走，并核文字/编号归属。

编号按约定的语法分词，不能去掉空格后直接比较；例如 `B 12#` 与 `B1 2#` 可能表示不同归属。最近的标签或相邻包围框只能作为候选线索。

若目标是 WPS/PPTX，还需使用相应演示文稿工具与校验流程，检查组坐标、裁剪、字体和线宽；本 skill 不代替那个格式的编辑能力。解析器遇资源上限时记录未完成的检查及补充证据，不能降低或修改托管校验器来制造通过。
