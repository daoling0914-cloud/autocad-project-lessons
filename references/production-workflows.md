# 生产流程与输出选择

技能入口把原生 AutoCAD 与 text-to-cad 两类生产路线接入同一套交付经验。根据当前输出要求选择，不能因另一条路线更容易就改变用户要的文件或编辑能力。

## 运行前判断

| 用户实际需要 | 采用的路线 | 直接产物 |
| --- | --- | --- |
| 可继续编辑文字、尺寸、图层的 DWG | AutoCAD 原生，必要时先生成原生 DXF | DWG；按需从最终 DWG 打印 PDF |
| 参数三维、零件/装配修改 | text-to-cad + build123d | 服务器模型；按需导出 STEP/STL/3MF/GLB/XBF |
| 切割轮廓、平板几何及展平 | text-to-cad 二维绘图 | 经轮廓检查导出的 DXF |
| 模型派生工程图 | `cad.eng_drawing` | 带投影视图和标注的 PDF |

工程 PDF 路线不自动提供对应 DWG。CAM 轮廓里的文字可能是雕刻轮廓；要保留原生 TEXT/DIMENSION 的普通工程图，应采用原生绘图路线。切割轮廓的闭合规则也不应套到建筑轴线、管线或尺寸延长线上。

先发现现有可执行文件和运行时，使用当前已验证环境。随附上游指南的安装命令只用于确实需要安装且环境允许的场合；融合技能本身不要求执行 setup、update、doctor 或重写其他应用配置。不要把安装成功、脚本运行成功与图纸验收通过混为一谈。

## AutoCAD native

1. 检查原 DWG 或提取参考尺寸、基准、轮廓、层级、单位和交付要求。局改保留原件并记录允许变化项。
2. 以本项目已有 AutoCAD .NET/COM/LISP 管线生成或修改对象。新图可用可用的 DXF 库编排原生线、弧、多段线、文字和尺寸，再导入 AutoCAD；文字、图层和打印样式按任务设定。
3. 几何构造与标注分开：先得到受尺寸约束的几何，再将原生尺寸、公差和引线关联到正确位置；用户要求无尺寸时仅验证约束。
4. 在副本中执行建图/改图，按所需枚举保存真正的目标 DWG 版本。记录本轮输出及错误，避免沿用旧文件。
5. 重新打开最终 DWG、回读关键对象和量测、执行原生审计，再从该文件打印所需布局或窗口。

具体构造随实际图种实现；用 [原生执行](native-execution.md)、[几何与修订](drawing-quality.md) 和 [兼容与打印](compatibility-and-plotting.md) 解决该阶段问题。本包不附带特定版本的 AutoCAD 二进制或 SDK。

## 三维、DXF 与投影图的同源循环

先读相应上游 guide，再使用其所需的参考；无需一次载入整套文档。

- 模型脚本把尺寸设为有意义的常量，`@model` 函数返回几何，在 `__main__` 中调用。运行 `cad run <脚本>` 得到实际模型标识；建模本身不等于已导出文件。
- 对应的二维轮廓从同一模型的几何派生，落在 z=0。通过 `cad export` 或 `cad.export` 导出 DXF，按 CUT/刻线/参考等用途组织图层；不能把 3D 实体直接压成未经说明的 XY 影子。
- 模型派生 PDF 的视图及尺寸点使用模型坐标，读取模型事实；投影法按当前要求明确设置。公差来自设计要求，未给定时保持名义值或询问，不能复制示例公差。
- 修改尺寸后重新运行受影响模型及其派生文件，回读实际导出文件，并按需查看模型快照和 PDF。STEP、DXF、PDF 的生成与验收结果分别记录。

### 随包示例

复制 `assets/starter-project/` 到本次工作目录，例如 `tmp/plate-demo/`。保持四个文件相邻，运行：

```powershell
cad run tmp/plate-demo/plate.py
cad run tmp/plate-demo/exports.py
cad run tmp/plate-demo/plate_sheet.py
```

示例在复制目录下的 `output/` 生成 `plate.step`、`plate_profile.dxf`、`plate.pdf`。参数集中在 `plate.py`；轮廓和工程图复用该模型。单独运行 `plate_profile.py` 只建二维模型，导出仍由 `exports.py` 完成。

示例用于验证已安装运行时与生产链路，不宣称它能代表全部装配、机构、DXF 展平、剖面或中文原生 DWG 能力。不同 text-to-cad 版本的 API 以本机可用行为为准；发生差异时先定位，不通过删减用户特征来“跑通”。

本次示例试跑曾发现自动等轴测标签越过图框，随后改为显式位置和比例并重新渲染。自动排布或未报告碰撞也不能替代对标签、图框和引线的视觉检查；示例位置不是所有零件均适用的固定值。

## 用经验检查生产结果

产出所需文件后，按此次修改选择几何、原生对象、编辑层级、字体和打印检查。任务清单工具可核对文件及页数；没有执行原生回读、视觉复核或干涉检查时，不把它们标为通过。只需一个模型或一个导出格式时，不额外生成整套示例产物。
