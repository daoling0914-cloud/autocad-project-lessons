# 去标识化经验案例

首版整理日期：2026-11-11。经验来自一个 Windows / AutoCAD 2021 项目的实际脚本、错误日志、验收记录和用户纠正。这里不附原图、真实路径、聊天记录、身份或单位名称。其他版本和设备需要重新核对 API 与可用配置。

| 触发情形 | 观察到的问题或验收方法 | 形成的规则 | 证据边界 |
| --- | --- | --- | --- |
| 加工图尺寸集中写进说明表 | 用户指出图内尺寸和形位公差不足；修订将其分配到对应视图与引线 | 验收应核对每个要素的图内标注，不能只核对文字清单 | 已有用户反馈及修订交付记录 |
| 剖面台阶与倒角复绘 | 用户发现局部方向相反且缺粗实线 | 对照原图放大检查方向、投影和粗线连续性 | 已有针对性修订和回读检查 |
| 旧版保存后的中文 | 回读比较发现一段 MTEXT 改变；按源记录修复后再次核对 | 版本转换必须比较文字语义，并检查内嵌样式 | 已有差异记录及验证脚本；不是所有中文都会损坏 |
| 指定家具块分解 | 验收检查嵌套块、可见包围盒及非目标对象 | 只分解指定范围，比较世界坐标几何并保留其他内容 | 已有转换和验证脚本；包围盒不证明内部完全一致 |
| 新布局创建视口 | `Viewport.On` 抛 `eNotInPaperspace` | 从纸/模型空间、布局归属、数据库和事务上下文排查 | 故障已证实；没有证明唯一通用修复 |
| 原图图框定位 | 筛选后 `.First()` 抛空集合异常 | 输出候选与筛选依据，选择前确认前置条件 | 日志及后续成功导出记录；不能假定是哪一个筛选条件唯一导致 |
| 清理 PDF 导入遮挡 | 旧脚本预期 12 个白色对象，实际只找到 8 个 | 数量必须绑定当前输入；选择需结合用途和范围 | 日志证明硬编码不稳；不支持“所有白色都应删” |
| 只更新标题栏 | 用主体几何签名与块比例比对，确认文字变更外无变化 | 小修订也验证不应变化的主体，避免重建整张图 | 已有前后比对及交付记录 |
| A3、1:1 及两档线宽 | 验收在 PDF 中量取已知圆并读取实际线宽 | 页框、内容比例和线宽分别验证 | 已有最终 PDF 测量脚本；具体参数属于该次要求 |
| 管线符号连接 | 在原生 DWG 导出 DXF 后以点到曲线距离复验 | 在最终回读几何上验证连接，不只看生成数据 | 已有连接核验脚本 |
| 大坐标道路图、多布局 | 模型使用米、纸面使用毫米，视口用单位换算比例；箭头按块变换核验 | 明确模型/纸面单位并在世界坐标比较图块几何 | 已有图层、比例、块轮廓回读脚本；不代表测绘精度或标准符合性已获证明 |
| 多轮交付打包 | 检查 ZIP 中字节是否与本轮 DWG/PDF 完全一致 | 打包验收绑定当前输出，避免修了文件却发出旧包 | 已有包内容与哈希检查 |

每条经验只推广到有依据的范围。对特定图纸的对象数量、文字内容和精度，不作为其他任务的固定要求。新增经验优先补充或修正对应参考，避免复制整段历史对话。
